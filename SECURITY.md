# Security

Doppelganger currently has no authentication or authorization. The operator/engineer selector changes presentation only. Keep the service on a trusted local network and do not expose it publicly without adding access control. See [guarantees and limits](docs/limitations.md).

For a suspected vulnerability, avoid posting exploit details in a public issue. Use the repository's private vulnerability reporting channel if it is enabled, or ask the maintainer for a private contact route without including the exploit details in that request.

When reporting, include the affected version or commit, impact, reproduction steps and a proposed fix if available. Remove tokens, private plant data and credentials from logs or screenshots.
